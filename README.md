## Reserva natural

El proyecto consiste en desarrollar un sistema para la gestión y organización de las actividades 
de una reserva natural. La aplicación permitirá administrar información relacionada con los 
visitantes, recorridos, guías, espacios naturales y salidas programadas, facilitando la
planificación  y el control de las actividades que se realizan dentro de la reserva.

## Requisitos
- .NET 8 SDK
- Visual Studio (opcional)
